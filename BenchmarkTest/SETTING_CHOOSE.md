# Выбор настроек для бенчмарка.

## CPU тест
Для этого теста нам важно, чтобы был загружен только процессор, поэтому необходимо поставить все настройки графики на минимум.

Разрешение экрана снижено до 1280x720, чтобы разгрузить графический чип. Масштаб разрешения также уменьшен до 50%. Качество графики поставлено на минимум. Трассировка лучей отключена.

## GPU тест
Для этого теста нам важно полностью нагрузить видеокарту.

Разрешение экрана поставлено на 1920x1080. Масштаб разрешения выставлен на 100%. Качество графики установлено на максимум. Трассировка лучей включена.

Все это позволяет загрузить видеокарту на максимум.
